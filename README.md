# 📚 Student To-Do List Reminder

A simple **Python desktop application** built using **Tkinter** that helps students create a to-do list and set a time-based reminder for their tasks.

## 📝 About the Project

The **Student To-Do List Reminder** provides a simple graphical interface where users can:

* Add tasks to a to-do list
* Set a reminder time in seconds
* View added tasks in a list
* Receive reminders when the specified time is reached
* Exit the application easily

The project is designed as a beginner-friendly Python GUI application and demonstrates the use of **Tkinter widgets, buttons, input fields, lists, events, and message boxes**.

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter**
* **Tkinter MessageBox**

## ✨ Features

* 📝 Add tasks
* ⏱️ Set reminder time in seconds
* 📋 Display tasks in a list
* 🔔 Task reminder functionality
* 🖥️ Simple graphical user interface
* ❌ Exit button
* ⌨️ Keyboard support for adding tasks

## 🖥️ How It Works

1. Enter a task in the **Enter Tasks To Do** field.
2. Enter the reminder time in **seconds**.
3. Click **Add Task**.
4. The task is displayed in the task list.
5. After the specified time, the application can show a reminder.
6. Click **Exit** to close the application.
